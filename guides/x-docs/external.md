# Connect X Docs

X Docs is public. You do not need an X account, developer app, API access, credentials, or a paid plan, and you do not need to sign in to X.

### Confirm the X Docs server {#confirm-x-docs-server}

Use this fixed remote URL:

```text
https://docs.x.com/mcp
```

Do not substitute this URL; it is for the separate X API MCP Server:

```text
https://api.x.com/mcp
```
