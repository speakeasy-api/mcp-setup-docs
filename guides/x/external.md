# Connect X to the Speakeasy AI Control Plane

X's public documentation MCP Server requires no X account, developer app,
API credits, or provider credentials. There is no provider console setup.

### Confirm the public documentation server {#confirm-public-docs-server}

Confirm that the MCP Server URL is `https://docs.x.com/mcp`. Do not substitute
`https://api.x.com/mcp`; that is X's separate API MCP Server.
