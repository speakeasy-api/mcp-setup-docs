## What the human said

The guide's "enable the integration in the Admin Console" flow "veers quite a
lot" from Box's actual docs — "Some of the pages seem made up, etc. Or maybe
you used outdated docs?" — citing
<https://docs.box.com/en/box-mcp/configuring-box-mcp-server/claude-code>,
whose admin flow (verified against a screenshot of that page) is:

1. Sign in to the **Box Admin Console**.
2. Go to **Integrations** and find **Custom Box MCP Server** either by using
   the **MCP Category** filter, or by using the search bar at the top of the
   page.
3. Go to **Configuration** > **Add Integration Credentials** to generate new
   credentials.
4. In **Redirect URIs**, change the Box redirect URIs to the connecting
   client's callback URL (the Claude Code page shows
   `http://localhost:PORT/callback`).
5. Copy the **Client ID** and **Client Secret** for later use.
6. Check the **Access scopes**.
7. Click **Save**.

## What the pipeline had done

The Technical Research Agent built the Dossier's console-flow facts from
`developer.box.com/guides/box-mcp/setup/` plus support articles. That page
describes a materially different flow (search "Box MCP server" → hover →
**Configure** → **Additional Configuration** → **+ Add Integration
Credentials** → name + **Save** → expand entry → copy credentials → enter
Redirect URI → select Access Scopes) and spells the tile name differently.
The agent never discovered `docs.box.com` — Box's current product-docs site,
which has a full Box MCP section (`/en/box-mcp`, `/en/box-mcp/tools`,
`/en/box-mcp/supported-ai-platforms`, per-client pages under
`/en/box-mcp/configuring-box-mcp-server/`) and a machine-readable index at
`https://docs.box.com/llms.txt`.

Downstream effects in the draft: a hover-then-Configure step the current
console apparently doesn't use; an either/or hedge on the tile name ("Box MCP
server" vs "Custom Box MCP Server" — docs.box.com is definitive: **Custom Box
MCP Server**); open questions about scope-checkbox labels ("Access scopes" per
docs.box.com) and about whether the credential entry needs a Save (it does —
step 7) that the right source answers outright.
