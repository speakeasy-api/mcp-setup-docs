# Proposals

Design proposals for the guide contract — the schema, the Go module API, and
what consumers can rely on. One numbered file per proposal: `NNNN-short-slug.md`.

A proposal argues for a change and records the reasoning; it does not make it.
Landing one means a normal PR against `schema/`, `go/`, or `pipeline/`, and —
where doctrine is affected — a human-approved change through the rules in
[`../doctrine/constitution.md`](../doctrine/constitution.md).

Put a `**Status:**` line at the top: `Proposed`, `Accepted`, `Rejected`,
`Superseded by NNNN`, or `Implemented`. Amend a proposal freely while it is
`Proposed`; once it is decided, write a new one rather than rewriting history.

Distinct from [`../research/`](../research/), which holds measurements rather
than arguments.
